- 本地集成测试：17 项，覆盖四种格式、权限与来源检查、索引变化、课程范围过滤、上传防覆盖、记忆编辑与恢复、串行队列与重连、备份完整性及模型密钥过滤。

- 合成规模测试：100 份文件（50 PDF、50 PPTX），每份 100 页或幻灯片，共 10,000 位置全部成功建立索引；首次约 9.57 秒，未变化复查约 0.37 秒，限定课程检索约 17.22 毫秒，SQLite 约 7.2 MB。
- 规模数据来自较小、重复的合成文字材料，不能外推复杂真实讲义的速度、召回率或公式提取质量。
- 运行资源已随项目本地提供，Markdown / HTML 清理由 DOMPurify 处理；Windows JavaScript MIME 类型已显式设置以避免浏览器拒绝脚本。

## 验收场景

| 场景 | 通过条件 |
| --- | --- |
| 上传及索引 | 四类文件均有处理结果；空文本/失败可见；同名不静默覆盖 |
| 中文与术语搜索 | 中文问题经模型扩词能定位正确片段；限定课程不越界 |
| 概念解释 | 内容有依据，引用可定位，补充知识不伪装成资料原文 |
| 跨文件比较 | 读取双方材料后比较，分别附对应来源 |
| 无答案 | 不捏造来源，必要时解释检索不足 |
| 版本变化 | 修改/删除后旧记录不冒充最新依据，相关理解待复核 |
| 对话教学 | 按要求进入教学，记忆区分用户反馈与练习证据 |
| 用户编辑 | AI 更新和撤销均不覆盖用户后续修改 |
| 断线与重启 | 网页关闭任务继续；重启中断任务不自动重放，队列保留 |
| 权限 | 未登录不能读资料/历史/记忆；路径越界及资料内指令不能扩权 |
| 备份恢复 | 使用一致性快照恢复数据库和记忆，避免运行时直接拷贝造成不一致 |

首个课程、资料文件与内容特点：待用户提供。合成测试不能代替真实课程验收。扫描内容和公式缺失必须在真实样本阶段评估。
