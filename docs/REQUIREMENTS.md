# 第一版需求

确认日期：2026-10-26。依据：用户 Q1–Q49 访谈及后续修订。本文记录已确认需求；架构中的实现建议不等于额外用户要求。

2026-10-27 后续确认：用户手机和主机已使用 Tailscale，授权改用 Tailscale Serve 固定私网 HTTPS 入口。该选择取代早期“手机不依赖组网客户端”的访问约束；公网临时隧道仅作为显式可选方案，无需购买域名。

## 产品与访问

- Android、电脑共用响应式网页，支持 PWA 桌面入口。
- Windows 个人电脑运行服务，手动启动；主机离线时不能新建问答和索引任务，界面明确提示。
- 外出通过 HTTPS 网址访问，手机无需组网客户端；允许主机运行连接服务。服务商与固定域名待验证，不承诺 chatgpt.site 可直接指向主机。
- 单用户、个人账户密码登录，支持多设备；不用 ChatGPT 账户登录，不开放注册。
- 四个入口：聊天、资料库、记忆、设置。支持 Markdown、数学公式展示。

## 会话与任务

- 多个聊天独立上下文，共享资料库和长期记忆。
- 一个 Agent，全局同时执行一个任务，新消息默认排队。
- 仅返回最终自然语言回答，不流式展示草稿。过程中显示真实状态，不展示内部思维链和虚构进度；不要求操作日志界面。
- 页面关闭或断线不取消主机任务；重新打开能恢复状态和结果，暂不推送通知。
- 工具调用次数、执行时间有可配置上限，具体默认值待实测。
- 重启后恢复尚未开始的排队任务，执行中的任务标为中断，由用户重试；不自动重放不确定写入。
- 当前聊天加载近期上下文，较早聊天通过工具按需检索。

## 资料与检索

- 一个统一原件目录，允许课程、主题子目录。用户可在主机放入文件或通过网页上传。
- 支持 PDF、PPTX、Markdown、DOCX 的文字提取。扫描页、图片、复杂公式识别留后续；检测到的异常必须提示，不能承诺发现全部提取错误。
- 预计 10 门课，每门约 10 份资料，每份约 100 页或幻灯片，总计约 1 万页。
- 自动发现新增、修改、删除并增量更新，提供手动刷新；目标为几十秒内开始处理，不承诺固定完成时间。
- 导入时提取文字及位置，建立本地全文索引，不逐页调用模型生成摘要和标签。
- DeepSeek 根据问题生成关键词、同义词和相关术语，调用本地搜索并自主多轮阅读、换词检索。第一版不使用向量模型或向量索引。
- 默认可检索全库；聊天可限定课程或文件，用户限定范围优先。
- 可按需将课程名、文件名、目录、命中片段和相关上下文发送给 DeepSeek，不默认发送整库。
- PDF 来源定位到页；PPTX 到幻灯片提取内容；DOCX、Markdown 到段落。提供原件查看或下载；PPTX/Word 原版排版预览后续增强。
- 引用必须对应实际读取的原文与版本。变化中的资料不能冒充最新依据。

## 回答与教学

- 云端模型按用户指定的 DeepSeek 1017 Flash 版本接入，实际模型标识由官方文档核验并可配置。
- 默认直接回答，明确要求教学时才分步骤讲解、举例和练习。
- 可使用模型知识补充，语言自然，不强制“额外解释”等固定栏目；不能把补充说成来源于资料。
- 无足够依据时说明局限；第一版不开放联网搜索。
- 学习状态记录“用户表示理解”或具体练习表现，不因讲解过、未追问就判定掌握。

## 记忆与原件权限

- Markdown 三类记忆：用户偏好与背景、学习记录、带来源的资料理解。
- 允许 Agent 自动写入，区分用户事实与助手推测；不把完整聊天重复保存为记忆。
- 偏好影响表达、学习记录帮助教学、理解笔记帮助查找；讲义事实仍须核对原件。
- 用户编辑优先，冲突由用户处理；尽量以条目为单位保护，无法可靠定位时保守保护整份文件。
- 原件变化或删除，相关理解保留并标记待复核，不删除学习记录。
- 每次 AI 修改保留前后修订，可无冲突撤销；后续用户修改不得被撤销覆盖。
- 删除聊天、记忆和资料分别处理，删除聊天时说明长期记忆可能保留。
- Agent 不修改或删除原件；网页第一版不提供原件删除，用户在主机操作。同名上传不得静默覆盖。
- 总结、练习等完整产物在用户明确要求时保存到独立目录。
- 资料内容是数据，不是执行指令。工具限制在资料、历史、记忆所需范围，不提供任意 Shell 或任意路径访问。
- API 密钥仅保存在主机端，不进入浏览器代码、资料工具结果或记忆。
- 提供手动备份方式，自动异地备份暂缓。
